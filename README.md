# xuanFP · AI 智能股票工作台

隔夜选股工作台：基于**真实可靠的 EOD（前一交易日收盘）数据**，用「全能多因子选股扫描仪」（**9 大维度、57 个因子**：基本面 + 细化技术指标 + 筹码分布 + 自研情绪因子）对**全 A 股**打分排名，输出 **Top 10** + 投资建议标签 + Top 3 核心逻辑，并为个股生成 AI 分析报告，附带 **Top10 双模式历史回测**（普通/短线）与 **14:25 短线榜单邮件推送**。

> 📐 **架构说明见 [ARCHITECTURE.md](ARCHITECTURE.md)**——防御型分层架构（api → services → domain → repositories → datasources）+ SQLite WAL/迁移，是所有后续更新的统一规范。

## 核心能力

1. **全市场多因子扫描**：硬性剔除 → 财务入围门槛 → 九维 57 因子评分（因子绝对分 + 维度/综合双重百分位校准）→ 综合排名 **Top 10**
2. **双模式扫描**：📊**综合模式**（均衡权重，15:00 收盘标准时点）与 ⚡**短线模式**（趋势/量价/资金/情绪权重放大、PE 上限放宽到 300，14:25 标准时点）
3. **投资建议标签**：按综合得分给出「建议加仓 / 建议买入 / 建议持有 / 建议观望 / 建议回避」五档建议
4. **Top10 双模式回测**：回测库只记录标准时点扫描（短线 14:25 / 标准 15:00，两套独立），可配置持有期 N 个交易日，统计平均收益 / 胜率 / 每批明细 / **次日卖点（开盘/最高/收盘）** / 收益走势（纯读库，东财→腾讯→新浪 K 线兜底）
5. **14:25 邮件推送**：「📮明日推送」安排次日 14:25 自动短线扫描并发邮件（Top10 + 核心亮点 + 次日止盈/止损价）；「🔔立即预演」随时手动触发
6. **AI 分析报告**：大模型（DeepSeek / OpenAI 兼容接口）为个股生成基本面/技术面/风险解读（未配置 Key 时自动降级为模板报告）
7. **扫描历史对比**：两次扫描的排名升降、得分变化、新上榜/掉榜，支持单条记录删除（列表标注扫描模式与时点）
8. **个股详情抽屉**：K 线图（MA5/10/20/60）、九维雷达图、57 因子明细、AI 报告

## 目录结构

```
xuanFP/
├── backend/                 # FastAPI 后端（防御型分层）
│   ├── main.py              # 入口（组合根挂载静态前端）
│   ├── container.py         # 依赖装配（唯一知道所有具体实现的模块）
│   ├── api/                 # HTTP 接口层（扫描/行情/历史/回测/配置）
│   ├── services/            # 应用服务层（扫描生命周期/Top10 回测/邮件推送/历史对比）
│   ├── domain/scanner/      # 核心领域层（57 因子、九维评分、剔除、引擎）
│   ├── repositories/        # 数据访问层（封装全部 SQL，SQLite WAL+迁移）
│   ├── datasources/         # 外部数据源（东财/腾讯/新浪，多主机容灾）
│   └── llm/                 # 大模型报告生成（含 Mock 兜底）
├── frontend/static/         # 免构建前端（Vue3 + Element Plus + ECharts 全局构建）
├── scripts/                 # 依赖下载、数据源测试、评分校验脚本
├── pylibs/                  # 后端依赖（离线安装，见下，不入库）
├── config.yaml              # 配置文件（不含任何密钥，可安全上传）
└── 启动xuanFP.bat            # 一键启动（双击即可）
```

## 安装与启动

### 1. 安装后端依赖（已内置离线安装器）

> ⚠️ **关于 Python 版本**：本机系统的 `python` 命令可能指向 3.14（不兼容本项目）。请优先用**项目自带的 `python3.bat`**（已强制指向配套的 3.13），或先运行一次 `修复python环境.bat` 把 3.13 加入 PATH。

pip 无法直接安装时，用自带的下载器（走 PyPI 直链）：

```powershell
cd xuanFP
python3.bat scripts/fetch_deps.py      # 下载并解压依赖到 pylibs/
python3.bat scripts/fetch_frontend.py  # 下载前端 Vue/ElementPlus/ECharts 到 frontend/static/vendor/
```

### 2. 配置密钥（重要）

`config.yaml` 已不含密钥（可安全上传 GitHub）。你的真实 API 密钥写在本地的 `config.local.yaml`（已被 `.gitignore` 排除，不会提交）：

```yaml
# config.local.yaml
llm:
  api_key: "sk-xxxxxxxx"   # DeepSeek 等（可选，留空则用模板报告）
```

也可以直接在工作台界面「⚙ 设置」里填写，效果相同。

### 3. 启动

**双击项目根目录下的 `启动xuanFP.bat`** 即可（会启动后端服务并自动打开浏览器 http://127.0.0.1:8710/）。

- 关闭那个黑色窗口 = 停止服务
- 若服务已在运行，脚本会自动识别并直接打开浏览器，不会重复启动
- **服务崩溃会自动重启**（5 秒后自动拉起），保证工作台持续可用

> 辅助脚本：`python3.bat`（用配套 3.13 运行任意脚本）、`修复python环境.bat`（一次性把 3.13 加入 PATH，让 `python` 命令恢复正常）。

## 扫描流程

1. **全市场快照**：一次拉取约 5500+ 只 A 股实时快照
2. **硬性剔除（一票否决）**：ST/\*ST、停牌、上市<90 交易日、当日成交额<8000 万、PE-TTM 不在 (0,80)（短线模式放宽到 300）
3. **财务门槛**：ROE>6%、营收同比>3%、资产负债率<78%（来自真实财报）
4. **九维评分**：综合模式 价值(13%)·质量(16%)·成长(15%)·趋势(11%)·量价(10%)·资金(11%)·情绪(12%)·安全(7%)·宏观(5%)；短线模式 趋势(18%)·量价(16%)·资金(16%)·情绪(16%) 为主 —— 因子绝对打分 + 头部非线性拉伸校准
5. **输出**：Top 10 排名表（含次日止盈/止损价）、投资建议标签、Top 3 核心逻辑、历史存档、标准时点批次自动入库

## Top10 双模式回测（复盘选股效果）

- **两套独立回测**：📊普通回测 / ⚡短线回测，互不干扰
- **回测库只记录标准时点扫描**：短线 14:25（14:20~14:35 窗口）、标准 15:00（15:00~15:20 窗口，工作日自动扫描）；时点外的扫描只进历史对比、不进回测库
- 可配置**持有期 N 个交易日**，统计**平均收益 / 胜率 / 次日卖点（开盘/最高/收盘）**，每只股票一行展示
- 尚未走满 N 个交易日的批次自动跳过（界面有提示）；数据随每日标准时点扫描自动积累

## 14:25 短线榜单邮件推送

- 「📮**明日推送**」：安排次日 14:25 自动跑短线扫描并发邮件（一次性；已安排时再点=取消）
- 「🔔**立即预演**」：随时手动触发一次（短线扫描+发邮件）
- 邮件内容：Top10 表格（排名/代码/名称/现价/涨跌幅/得分/建议/次日止盈/次日止损/核心亮点）
- 需在「⚙设置」填写 QQ 邮箱 + SMTP 授权码 + 收件邮箱（授权码写入 config.local.yaml，不会上传）
- ⚠️ 到时需**电脑开机且 xuanFP 在运行**；错过不补发
