# xuanFP · AI 智能股票工作台

隔夜选股工作台：基于**真实可靠的 EOD（前一交易日收盘）数据**，用「全能多因子选股扫描仪」（9 大维度、37 个因子）对**全 A 股**打分排名，输出 Top 20 + 强烈关注标注 + Top 3 核心逻辑，并为个股生成 AI 分析报告。

## 核心能力

1. **全市场多因子扫描**：硬性剔除 → 财务入围门槛 → 九维 37 因子百分制评分 → 综合排名 Top 20
2. **AI 分析报告**：大模型（DeepSeek / OpenAI 兼容接口）为个股生成基本面/技术面/风险解读（未配置 Key 时自动降级为模板报告）
3. **扫描历史对比**：两次扫描的排名升降、得分变化、新上榜/掉榜
4. **个股详情抽屉**：K 线图（MA5/10/20/60）、九维雷达图、37 因子明细、AI 报告

## 安装与启动

### 1. 安装后端依赖（已内置离线安装器）

pip 无法直接安装时，用自带的下载器（走 PyPI 直链 + 清华镜像）：

```powershell
cd xuanFP
python scripts/fetch_deps.py      # 下载并解压依赖到 pylibs/
python scripts/fetch_frontend.py  # 下载前端 Vue/ElementPlus/ECharts 到 frontend/static/vendor/
```

### 2. 配置密钥（重要）

`config.yaml` 已不含密钥（可安全上传 GitHub）。你的真实 API 密钥写在本地的 `config.local.yaml`（已被 `.gitignore` 排除，不会提交）：

```yaml
# config.local.yaml
tushare:
  pcd: { api_key: "你的PCD密钥" }
  rds: { api_key: "你的RDS密钥" }
llm:
  api_key: "sk-xxxxxxxx"   # DeepSeek 等
```

也可以直接在工作台界面「⚙ 设置」里填写，效果相同。

### 3. 启动

```powershell
cd xuanFP
.\run.ps1            # 或双击 run.bat
```

浏览器打开 **http://127.0.0.1:8710/** 即可。

### 4. 配置大模型（可选）

在界面「⚙ 设置」里填入 DeepSeek 或任意 OpenAI 兼容接口的 base_url / api_key / model，保存后报告将由大模型生成；留空则使用内置模板报告。

## 扫描流程

1. **全市场快照**：一次拉取约 5551 只 A 股实时快照
2. **硬性剔除（一票否决）**：ST/\*ST、停牌、上市<90 交易日、当日成交额<8000 万、PE-TTM 不在 (0,80)
3. **财务门槛**：ROE>6%、营收同比>3%、资产负债率<78%（来自真实财报）
4. **九维评分**：价值估值(12%) · 资产质量(18%) · 盈利成长(15%) · 趋势技术面(13%) · 量价动能(12%) · 主力资金流(13%) · 筹码与情绪(8%) · 安全边际(5%) · 景气与宏观(4%)
5. **输出**：Top 20 排名表、综合得分>85 标注【强烈关注】、Top 3 核心逻辑、历史存档

## 数据缺口与简化（诚实说明）

以下数据源无法稳定获取，对应因子**按 0 分计并触发维度降权**（权重按比例分摊给其他维度），报告中会明确标注：

- 股息率、北向持股、龙虎榜机构席位、大单净买入占比
- 筹码获利盘、股东户数、融资融券余额
- 行业库存周期、审计意见、大股东质押率

> 流动性门槛以**当日成交额**代理近 5 日均额；双高暴雷规则降级为商誉/净资产预警（质押率数据缺失）。
